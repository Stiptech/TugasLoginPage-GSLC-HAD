# Bengkel Motor

Aplikasi booking bengkel motor (sport dan skuter) untuk tugas Hybrid Application Development, topik Services.

Pelanggan bisa booking **Cuci**, **Service**, atau **Modif** dan mendapat nomor antrian terpisah per kategori per hari (`C-001`, `S-001`, `M-001`). Admin bengkel melihat antrian dan mengubah statusnya.

Dibuat dengan Expo, TypeScript, React Native, dan NativeWind.

## Menjalankan

```bash
npm install
npx expo start
```
